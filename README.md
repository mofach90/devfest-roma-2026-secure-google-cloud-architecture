# Building a Secure Web Architecture on Google Cloud

**DevFest Roma 2026** · Mohamed Islem Ayari · Cloud / Platform Engineer

A practical talk on evolving a simple web application into a secure, reliable, production-ready architecture on Google Cloud. The walkthrough starts with a single VM and builds toward a managed, scalable design, covering identity and access, networking, resilience, deployment, and protection from malicious traffic.
